# Desafio de IA com NotebookLM

## 📌 Descrição do Projeto
O objetivo do estudo foi poder avaliar quanto o tema "Inteligência Artificial" teve importância no maior evento de Cibersegurança do Brasil e quanto estão dando importância desta pauta no cenário nacional de cibersegurança.

## 📚 Fontes Utilizadas (Inputs)
- Site do "Evento Mind The Sec": https://www.mindthesec.com.br/
- Temas das palestras do evento "Mind The Sec": https://www.mindthesec.com.br/agenda

## 🤖 Como utilizei o NotebookLM
- Verifique a página "Agenda" e liste para mim todos os temas de palestras que envolveram IA.
- Qual é o percentual de palestras que abordarão o tema Inteligência Artificial em sua pauta.
- Geração do podcast/áudio de resumo (*Deep Dive*).

## 💡 Aprendizados e Conclusões
A ferramenta apresenta com precisão, todas as informações do conteúdo inserido como base para análises/estudos. Ajuda muito a se aprofundar e tirar conclusões importantes para diversos tipos de atividades.
